# screenshots/

界面截图放这里，供 README 引用。

## 建议命名

| 文件名 | 内容 | 说明 |
|--------|------|------|
| `overview.png` | 首页总览（功力九宫格） | README 首图 |
| `advice.png` | 「养成建议」决策工作台（五区） | 最能体现「如何思考」的一张 |
| `editor.png` | 某系统图形化编辑器 | 体现产品形态 |
| `duel.png` | PVE/PVP 对决结果 | 体现战斗模拟 |
| `import.png` | 截图导入（面板识别） | 体现数据管线 |
| `qa.png` | 直答问答卡 | 体现「顾问」定位 |

## 截图要求

- **尺寸**：建议 1600px 宽左右，横向（16:9 或更宽）。
- **内容**：先把示例玩家档案加载好再截，别出现空状态 / 报错 / 敏感路径。
- **脱敏**：⛔ 不要截到本机绝对路径、token、玩家隐私信息。
- **格式**：PNG。

## 怎么点亮 README 里的占位图

README 里现有 `![...](screenshots/overview.png)` 占位。把对应文件放进本目录即可；
其余图在 README 中新增一行引用，例如：

```markdown
![养成建议](screenshots/advice.png)
```
